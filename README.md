Smart phone Addiction is becoming a bigger problem in today's world, as humans rely of Smart Phones for various tasks including Productivity, Gaming, Office Work excessive use of smart phones result in smart phone addiction which impacts negatively on human life including anxiety, sadness, sleep difficulties. This project aims to develop a smartphone addiction prediction system using machine learning techniques to evaluate and classify addiction levels based on user responses to a structured question. The model utilizes survey data on smartphone usage patterns, and screen time, using analytic tools, and then the responses have been preprocessed and balanced using techniques like SMOTE to overcome class imbalances, a machine learning model is used to predict the level of addiction. The model's training and optimization gives accurate classifications, allowing users to understand better about their smartphone usage patterns.
Machine learning techniques, Flask, and Python are used to develop the model implementation to give an accurate and effective outcome. Users can select through a user-friendly interface and get instant results about their addiction levels after submitting the inputs. Feature selection is used to improve performance. The system also takes moral considerations like data security and privacy to protect the user’s privacy. By providing a user-friendly method for detecting smartphone addiction, this project gives self-awareness and effective digital habits.  Medical experts can understand the patterns of smart phone dependency and gives treatments with the help of system's observations.
